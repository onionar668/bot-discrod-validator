## Bot discord server
Сделал бота для дискород сервера, который валидирует участников

Как он работает: если в дискорде видно во что играет участник и он заходит в канал который не отсносится к данной игре, то бот его кикает и закидывает в нужный канал

Как его запустить: для того чтобы он работал на вашем сервере , необходимо запустить проект с помощью команды
```bash
$ npm start
```
и он будет запущен локально, затем с помощью функция дискорда для разработчиков закинуть его на свой сервер
